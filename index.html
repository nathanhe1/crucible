Why environments

Static test sets measure recall. Environments measure judgment.

A fixed question set can leak into training data and rewards answers that look right. An environment changes in response to what the model does, so the only way to score well is to act well, step after step.

01 · ObserveState, tools, and history arrive
02 · ActThe model calls tools or places orders
03 · RecordEach step is saved as a trajectory
04 · ScoreVerifiers check the resulting state
05 · TrainThe same record feeds your training loop
06 · Forward-testFreeze the checkpoint and run it on data it has never seen
Router

One command to run any suite against any model.

Pick a versioned suite and the model routes you care about, including your own OpenAI-compatible endpoint. Before anything runs, Router checks compatibility and estimates cost. Each run produces scores with confidence intervals, a reproducible manifest, and exports to JSON, CSV, or HTML.
